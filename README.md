# Atlas Opportunity OS

Atlas Opportunity OS is a premium, deeply personalized AI-powered university and global opportunities management platform for one ambitious engineering student planning international education, scholarships, relocation, and long-term career growth.

## What it includes

- Personalized university application tracker with deadlines, tuition, rent, living costs, AI admission probability, scholarship probability, and migration scoring.
- Scholarship, fully funded opportunity, internship, assistantship, fee waiver, and career sprint feed.
- Country comparison analytics for post-study work routes, permanent residency probability, safety, quality of life, cloud demand, and telecom demand.
- AI recommendation cards for SOP, CV, scholarship strategy, portfolio strengthening, housing timing, and financial risk control.
- Future career simulator, Fall 2027 execution roadmap, and private command-center dashboard UI.
- API route for intelligence data aggregation and a PostgreSQL-ready Prisma schema for scalable persistence.

## Tech stack

- Next.js / React frontend
- Node.js API route layer
- PostgreSQL-ready Prisma data model
- Modular TypeScript data layer for future AI, scholarship, housing, jobs, currency, and university integrations

## Running locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
